# 外围描边透明化修正验证（2026-11-11）

用户明确：心形勤学牌只抠除黑色外围描边，内部白色牌面保留。旧版实际把 39,541 个可见像素改为不透明白色，这些像素的 alpha 均未减少；旧结论不符合当前要求。

## 规则和实现

- Skill 与批处理统一要求外围附加描边抠成透明，禁止通过补白或补主体色替代。内部实体上的局部修复仍可补色。
- `erase_edge` 在授权区域和外缘带内，仅清除与外缘连通的暗线；保护区和不连通的内部细节保持不变。
- 去边后可用 `clear_specks` 清理语义上确认属于背景的微小孤立分量，保护主体与合法细节；不会通过继续内缩整个牌面清理孤点。
- PNG 视觉输入先按真实 alpha 合成灰底 RGB 预览，避免透明像素的隐藏 RGB 被图像通道当作可见黑边。独立验收增加 alpha 蒙版证据和 `removed_border_is_transparent` 必需条件。
- 版本改为 `batch-v2-transparent-edge`。旧批次不可直接续跑或复用旧通过结论，需重新导入；历史记录保留。

29 项离线回归通过，新增覆盖透明去框、白色牌面与保护区保留、邻近不连通黑色细节保留、禁止旧补色方案、禁止局部补色覆盖外轮廓、旧批次拒绝续跑、透明预览合成与背景孤点清理。仓库及已安装 Skill 的结构检查通过。

## 自动化限制

开发期间有多次修正和重试。最新自动批次已完成黑框透明化并保留主体，但在两轮补修上限内未完全覆盖浅色残点，仍归入异常；没有将其改标通过。最终交付是在该批次之外，由主代理确认全部 47 个外围孤点、逐点限定范围补修的结果。它证明透明去框及定点补修可以完成此图，不证明自动批处理已能一次完成全部新素材。

客户图片、PSD、模型日志及开发辅助脚本仅保存在本地，不提交至公共仓库。历史补色样本不得计入新规则成功率。
