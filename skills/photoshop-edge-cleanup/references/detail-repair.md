# 局部边框与彩色混边

用于首轮已基本完成、但仍有局部残线的素材。先看原图、已有结果及对应参考/用户指出的部位。以下方法在“小心地滑”深灰标题与“小四班”绿色花朵上验证过；坐标、阈值和边宽必须按新图重估。

## 区分三类边界

- 整体轮廓：主体与透明区相接，适合用 alpha 边缘带约束。
- 子图形边界：标题胶囊、前后叠板等与底板相接，其描边可能在整体轮廓内部。确定需要清除后，为这一条边另建局部范围；不受只针对整体轮廓的 edge_limit 截断。
- 交汇点：花瓣与白板、标题与白板的接点。旧外框可能藏在转折处成为短线或尖点。沿边追踪整个连接处，检查两侧，不只处理用户举例的一侧。

原图中有深色填块时，分开判断填色与附加细描边。保留填块形状、纹理和文字，在确认多余的窄边带内延展同材质颜色。不要用一块宽泛保护多边形同时保护填块和待清边框，也不要按“深色”阈值刷白整块标题。

## 按边界两侧的材质修复

1. 从原图确定子图形轮廓和窄修补带；白字可能让阈值分割出现洞，可填洞得到形状，但不能把文字本身当成修补目标。与底板线条相交的位置，借相邻轮廓延续确定真实边缘，排除旧线形成的凸点。对非规则形状不强套圆角矩形。
2. 子图形内侧：从邻近且属于同一填色/纹理的像素取样，替换附加黑框。避开文字、阴影、其他材料；不要仅选欧氏距离最近的像素。边带太宽会侵入正文，太窄会留暗边，按这段边的实际宽度决定。
3. 子图形外侧：接白板的残线补白板颜色；接透明区的边保持透明度，补主体颜色。白色底板和透明区必须分开，否则会在深底预览里留下白晕。不要在连接点跨材料采样，造成标题缺口或把白板补成灰色凸点。
4. 彩色边：黑线的抗锯齿会形成暗绿、暗红等混色，不能只检测 RGB 接近的中性黑。只在已确认要清除的彩色边带内，对比同色相邻近正常颜色和沿边连续性，修复异常变暗的混边。原有渐变、阴影和内部线条需保留。
5. 白切边内的黑尖点可补成白底色；彩色花瓣内的暗边用邻近花瓣颜色延展。处理完沿花瓣全边和接点再看一遍，防止大段边干净但剩一两个明显黑点。

现有 patch、paint、path 工具即可执行，不依赖新 Photoshop 插件。准备补片时，以原始画布大小保存 RGBA，只在已分析的范围赋予补片 alpha。原图新建 PS 副本，set_plan 后导入补片；方案更新不基于已经误删的失败版。需要延续一版已正确的处理时，可将其与原图差异及本轮修补合并为补片，保留版本来源与范围证据。

## 本轮验证

- 整图 100% 加局部 2–4 倍，同底色对比上一版/本次。重点看描边是否真正消失、交点有无凸刺/缺口、深色块是否出现不自然的补色接缝。
- 白底区分真实黑残点与透明凹缝；深底检查白晕。只看深底可能把透明凹缝误当黑边。
- 纯补色修整核对 alpha 逐像素不变；核对标题文字、人物、正文和花瓣内部的保留区域没有变化。视觉复核与这些像素检查同时使用。
- 比较准备的补片合成预览与 PS 最终 PNG，分别检查 RGB 和 alpha。Pillow 的 RGBA difference.getbbox() 默认可能只看 alpha；不能用它单独证明 RGB 无差异。
- 交付局部放大图时标明“上一版/本次”。只修改过的样本可以更新结果，不能据两张定向修复提高整批或未见样本的泛化成功率。

## 半透明边缘的补片合成

不透明补片叠加在半透明像素上会提高最终 alpha，即使 RGB 正确也可能形成过实的白边。先记录期望的原始 alpha，导入补片后读取实际 PNG。需要恢复透明度时，按像素计算乘法蒙版 `round(255 * target_alpha / current_alpha)`；`current_alpha == 0` 且目标也为 0 时用 255。若目标大于当前值，应回退检查，不用乘法蒙版尝试增加透明度。

只在允许范围内应用蒙版，随后分别检查可见 RGB 和 alpha。不能把原始 alpha 无差别乘到未改变的半透明像素上，否则会重复衰减。使用原图新开副本保存修正版，并保留上次实际 PS 导出检查点。

具体素材坐标和边宽不作为新图默认参数。测试图、客户素材和本地历史会话不属于本 skill 分发内容。
